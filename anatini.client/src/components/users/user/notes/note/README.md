# User Note
- Displays user note with correct HTML
- Links back to user note list
- Can star, bookmark, and dismiss
- Has link to open edit page if owner
- Cannot view protected note when not logged in
- Can view protected note when
  - logged in as owner
  - logged in as other user
- Can view public note when
  - not logged in
  - logged in as owner
  - logged in as other user
- Can view draft note when logged in as user
- Cannot view draft note when
  - not logged in
  - logged in as other user
- Can view archived note when logged in as user
- Cannot view archived note when
  - not logged in
  - logged in as other user
